# Personal Portfolio

A modern, responsive portfolio website built using React, Vite, Tailwind CSS, and Framer Motion.

## Features

- Responsive Design
- Modern UI
- Smooth Animations
- Project Showcase
- Skills Section
- Contact Form
- GitHub Integration

---

## Technologies

- React
- Vite
- Tailwind CSS
- Framer Motion
- React Router
- React Icons

---

```text
src/

```

## Installation

```bash
git clone https://github.com/HamzehAlBawaneh/portfolio.git

cd portfolio

npm install

npm run dev
```
